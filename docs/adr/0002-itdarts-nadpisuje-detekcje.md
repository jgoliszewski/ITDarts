# ITDarts nadpisuje detekcję Board Managera

Rzuty z Board Managera są tylko podpowiedzią. Po ręcznej poprawce lub dopisaniu rzutu z Pilota obowiązuje wersja ITDarts, a z Board Managera bierzemy już tylko nowe rzuty. Gdy tarcza jest niedostępna, mecz trwa dalej na rzutach wpisywanych ręcznie. Dzięki temu błędna detekcja ani awaria Board Managera nie psują meczu.
